# `sets/` —— 这一轮评测覆盖哪些题

清单是**纯声明**（今天没有它的机器消费者：0.13.0 那个对账脚本已按决策者判定删除），
一行一个题目 id，文件头的 `# count: N` 是**规模声明**。

形状与"为什么需要它"的完整说明只有一处：`experiments/README.md` 的任务目录小节。
这里只留最小形状，别在本文件里另写一套规则：

```text
# count: 8
<id>                 ← 一条题目；也可以写成 <id><TAB>备注
# 注释行与空行不计数
```

★ `# count:` 必须与实际条目数一致 —— 清单被截断到一半时文件照样"非空"，
只有这一栏能发现"评测范围悄悄变小了"。
